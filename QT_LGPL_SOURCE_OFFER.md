# Qt / PySide6 Corresponding Source Information

HPC Client GUI binary releases contain PySide6, Shiboken6, and Qt components
distributed under applicable LGPLv3 terms. The exact versions included in a
release are recorded in that release's generated `THIRD_PARTY_VERSIONS.txt`
manifest.

For those exact versions, corresponding-source records are provided through
the release-specific `QT_LGPL_SOURCES.json` metadata. A release may provide
the source archives as release assets or provide verified source URLs and
checksums together with the metadata. The release record, rather than a
generic link to the Qt homepage, identifies the source corresponding to the
distributed binaries.

Release materials should be used to identify the exact source corresponding to
the binary being redistributed. This project does not promise perpetual
hosting of a particular archive beyond the source and release materials it
maintains.
