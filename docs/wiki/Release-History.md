Published artifacts and their release notes are on the
[releases page](https://github.com/mskomek/hpc-client-gui/releases). The
current version is **1.2.6**.

This page deliberately does not restate the changelog. A second copy of release
history drifts from the first, and the copy people happen to read is then
wrong. Follow the links above.

## Two dates worth knowing

- **v1.2.0** changed the license from MIT to PolyForm Noncommercial 1.0.0. The
  MIT grant is not revoked for copies of earlier releases that were already
  distributed. See [[Licensing and Commercial Use|Licensing-and-Commercial-Use]].
- Linux artifacts — AppImage and `.deb` — are published alongside the Windows
  ZIP as of the current release line. See
  [[Installation on Linux|Installation-Linux]].

## In-application changelog

The application shows the changelog for the version you are running from the
help surface, so you do not need to visit GitHub to see what changed.
