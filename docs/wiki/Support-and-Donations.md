# Support and Donations

> Türkçe: [[Support-and-Donations-TR]]

## Getting help

1. Check [[Troubleshooting|Troubleshooting]] and [[FAQ|FAQ]] — they are
   organized by the symptom you observe.
2. Look at `~/.truba_slurm_gui/app.log`; it usually names the actual failure.
3. Open an issue on
   [GitHub](https://github.com/mskomek/hpc-client-gui/issues) with your
   version, operating system, what you did, and what happened.
4. Attach a diagnostic bundle — read it first. See
   [[Crash Reports and Send Logs|Crash-Reports-and-Send-Logs]].

For anything with security impact, do **not** open a public issue. Use GitHub's
Private Vulnerability Reporting — see [[Security Model|Security-Model]].

## What support is and is not

This is an independent community project maintained on a voluntary basis.
There is no response-time commitment and no support guarantee. Only the latest
published release receives fixes, so upgrade before reporting.

## Donations

Voluntary donations help support ongoing development, testing, documentation,
and release maintenance. GitHub Sponsors is configured for the repository
(`mskomek`), and Bitcoin is accepted; the current address is in `SUPPORT.md`
and `README.md` in the repository. Take the address from those files rather
than from a copy — including this page.

Donations are **completely optional**. They do not unlock features,
privileges, priority support, or support guarantees, and **a donation does not
grant commercial-use rights or constitute a commercial license**. Commercial
use requires a separate license — see
[[Licensing and Commercial Use|Licensing-and-Commercial-Use]].

## Other ways to help

- Report reproducible bugs with logs attached.
- Improve the documentation — this wiki is generated from `docs/wiki/` in the
  repository and is reviewed like code.
- Contribute translations; Turkish and English resources are updated together.
- See [[Contributing|Contributing]].
