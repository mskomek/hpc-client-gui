# Support HPC Client GUI

HPC Client GUI is developed and maintained as an independent community project.

If the project is useful in your research or HPC workflow and you would like to
support its continued development, voluntary sponsorships and donations are
appreciated.

Support can help with ongoing development, testing, documentation, release
maintenance, compatibility work, and future improvements.

## GitHub Sponsors

one-time contribution:

## Other Ways to Support the Project

Financial support is not required. You can also help by:

- starring the repository on GitHub;
- reporting reproducible bugs;
- suggesting useful HPC workflow improvements;
- improving documentation;
- contributing fixes through pull requests;
- sharing the project with other HPC and Slurm users.

Thank you for supporting the continued development of HPC Client GUI.
